## Construct FoldBench

### 1. Download Necessary Files
Please download the file `interface_protein_protein.csv` from the [FoldBench repository](https://github.com/BEAM-Labs/FoldBench).

### 2. Download Structure Files
Run `python download_structures.py` to download the necessary structure files.

### 3. Process Structures
Run `python process_structures.py` to process the downloaded structure files.
